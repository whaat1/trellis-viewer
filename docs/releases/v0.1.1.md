# Trellis Viewer v0.1.1

本次更新将社区贡献与任务视图、日历和项目管理改进一并打包。

## 下载

| 文件 | 用途 |
| --- | --- |
| `Trellis-Viewer_0.1.1_aarch64.dmg` | macOS 12+，Apple Silicon（M 系列） |
| `Trellis-Viewer_0.1.1_x64-setup.exe` | Windows x64 NSIS 安装包，面向 Windows 11 |
| `SHA256SUMS.txt` | 两个安装包的 SHA-256 校验值 |

安装与升级方法见[安装说明](https://github.com/whaat1/trellis-viewer/blob/v0.1.1/docs/installation.md)。macOS 使用 ad-hoc 签名，尚未经过 Apple 公证；Windows 安装包尚未签名。Windows 缺少 WebView2 时安装器需要联网补装。应用标识不变，升级保留项目登记、配色与排期；建议升级前备份应用数据目录。

## 改进

- 增加 Windows x64 安装包和跨平台任务、文档及事件路径处理。
- 项目列表支持拖拽排序、右键菜单和移除确认，重新添加同一路径可恢复配色与排期。
- macOS 可从右键菜单在 Finder 中显示项目、复制完整路径；Windows 暂禁用这两项。
- 日历支持为子任务排期，项目进度统计纳入归档任务并按原始完成状态计算。
- 父任务和文件夹可折叠，子任务与文件夹支持排序；任务区高度支持按行吸附。

## 验证范围

前后端测试、类型检查、Lint、Clippy、正式构建；macOS DMG 挂载与应用冒烟；Windows CI 检查安装、原生窗口启动与正常退出、示例源文件未变更、卸载。Windows CI 使用 Windows Server 2022，不代表完整 Windows 11 人工交互验收。完整大规模原生性能验收尚未完成。
