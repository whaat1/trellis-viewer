# Trellis Viewer v0.1.0

首个公开试用版：在一个本地窗口里阅读 Trellis 任务、父子关系与 Markdown 文档，并用月历安排不同项目的计划。

## 下载

| 文件 | 用途 |
| --- | --- |
| `Trellis-Viewer_0.1.0_aarch64.dmg` | macOS Apple Silicon（M 系列）应用 |
| `SHA256SUMS.txt` | DMG 的 SHA-256 校验值 |

macOS 12+；首版主要在 macOS 26 上验证。下载 DMG 后，将应用拖到 Applications。**当前为 ad-hoc 签名，尚未经过 Apple 公证**，首次打开可能被系统拦截，请先阅读 [安装说明](https://github.com/whaat1/trellis-viewer/blob/main/docs/installation.md)。

## 这一版能做什么

- 添加、切换多个本地 Trellis 项目。
- 按状态查看顶层任务，展开父子任务与 Markdown 文档目录。
- 查看子任务完成情况与项目完成度，自动刷新源文件变化。
- 在月历中安排顶层父任务和独立任务，拖动、跨日调整、清除计划。
- 为项目选择颜色，用于项目标记和日历色条。
- 拖动分隔线调整阅读布局，并记住布局与阅读位置。

源项目只读。配色和排期保存在应用自己的数据目录，不会改动原来的任务文件。

## 已知限制

图片预览、外链打开、自动更新和跨设备排期同步暂未提供。暂只发布 M 系列 Mac 安装包。大规模任务下的完整原生性能验收尚未完成，不作固定帧率或延迟承诺。
